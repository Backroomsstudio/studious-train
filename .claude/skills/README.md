# Skill installate per Claude Code

Skill di progetto: si caricano automaticamente in ogni sessione di Claude Code aperta su questo repository.
Si invocano con `/nome-skill` oppure Claude le usa da solo quando servono.

| Skill | Da repo | A cosa serve per lo studio |
|---|---|---|
| `ponytail`, `ponytail-review`, `ponytail-audit`, `ponytail-debt`, `ponytail-gain`, `ponytail-help` | [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail) | Sviluppatore senior: review, audit e debito tecnico del sito |
| `hallmark` | [nutlope/hallmark](https://github.com/nutlope/hallmark) | Landing page e grafiche con un look meno "generato da AI" |
| `humanizer` | [blader/humanizer](https://github.com/blader/humanizer) | Testi (post, bio, caption, email) più naturali |
| `taste-skill` (nome: `design-taste-frontend`) | [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) | Gusto estetico nel frontend |
| `impeccable` | [pbakaus/impeccable](https://github.com/pbakaus/impeccable) | Rifinitura e audit dell'interfaccia del sito |
| `ui-ux-pro-max`, `design`, `design-system`, `brand`, `banner-design`, `slides`, `ui-styling` | [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | UI/UX, brand identity, banner social, presentazioni |
| `last30days` | [mvanhorn/last30days-skill](https://github.com/mvanhorn/last30days-skill) | Trend degli ultimi 30 giorni (Reddit, X, YouTube...) per idee di contenuti |
| `scrapling` (nome: `scrapling-official`) | [D4Vinci/Scrapling](https://github.com/D4Vinci/Scrapling) | Raccolta dati dal web (competitor, prezzi, lead). Richiede `pip install scrapling` |
| `diagram-design` | [cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design) | Diagrammi (funnel clienti, flussi di lavoro) |

Ogni cartella mantiene la licenza originale del progetto (MIT, Apache 2.0, BSD).
Per aggiornare una skill: ri-clonare la repo e sostituire la cartella corrispondente.
